Etiquetas HTML y su uso

Número Nombre de la Etiqueta Descripción Ejemplo de Uso Elemento Adicional
1 <html> Etiqueta raíz del documento HTML. <html>...</html> Contiene todo el documento
2 <head> Contiene metadatos del documento. <head><title>Mi página</title></head> No es visible en la página
3 <title> Define el título en la pestaña del navegador. <title>Mi Sitio</title> Va dentro de <head>
4 <body> Contiene el contenido visible del documento. <body><h1>Hola</h1></body> Solo puede existir uno
5 <h1> Encabezado principal del documento. <h1>Título</h1> Existen hasta <h6>
6 <p> Define un párrafo de texto. <p>Texto aquí</p> Elemento en bloque
7 <a> Define un hipervínculo. <a href="https://google.com">Ir</a> Usa el atributo href
8 <img> Inserta una imagen en la página. <img src="foto.jpg" alt="Foto"> Requiere src y alt
9 <ul> Crea una lista desordenada. <ul><li>Item</li></ul> Usa <li>
10 <ol> Crea una lista ordenada. <ol><li>Item</li></ol> Lista numerada
11 <li> Elemento de una lista. <li>Elemento</li> Va dentro de <ul> u <ol>
12 <table> Define una tabla. <table>...</table> Contiene <tr>, <td>, <th>
13 <tr> Define una fila dentro de una tabla. <tr><td>Dato</td></tr> Va dentro de <table>
14 <td> Define una celda normal en una tabla. <td>Dato</td> Va dentro de <tr>
15 <th> Define una celda de encabezado. <th>Nombre</th> Texto en negrita por defecto
16 <form> Define un formulario para enviar datos. <form action="procesar.php"></form> Usa método GET o POST
17 <input> Campo de entrada de datos. <input type="text"> Muchos tipos: text, email, password
18 <button> Botón clickeable. <button>Enviar</button> Puede ser submit
19 <div> Contenedor en bloque. <div>Contenido</div> Muy usado con CSS
20 <span> Contenedor en línea. <span>Texto</span> No genera salto de línea
21 <nav> Define un contenedor de menú de navegación. <nav><ul><li>Enlace</li></ul></nav> Agrupa enlaces principales
22 <header> Define el encabezado de una página o sección. <header><h1>Mi Sitio</h1></header> Puede contener logos, títulos y navegación
23 <footer> Define el pie de página de una sección o documento. <footer>© 2026 Mi Sitio</footer> Normalmente contiene información de contacto
24 <section> Define una sección dentro del documento. <section><h2>Noticias</h2></section> Organiza el contenido por bloques
25 <article> Representa contenido independiente como un artículo o publicación. <article><p>Contenido</p></article> Muy usado en blogs
26 <aside> Define contenido secundario o complementario. <aside>Publicidad</aside> Usado para barras laterales
27 <br> Inserta un salto de línea. Hola<br>Mundo No necesita etiqueta de cierre
28 <hr> Inserta una línea horizontal. <hr> Se usa para separar contenido
29 <strong> Indica texto importante en negrita. <strong>Importante</strong> Tiene valor semántico
30 <em> Indica énfasis en el texto. <em>Énfasis</em> Se muestra en cursiva
31 <code> Define un fragmento de código. <code>print("Hola")</code> Usado para mostrar código fuente
32 <pre> Define texto preformateado. <pre>
Texto con espacios
</pre>		 Preserva espacios y saltos de línea
33 <iframe> Inserta un marco con contenido externo. <iframe src="https://www.youtube.com/embed/videoID"></iframe> Usado para videos, mapas, etc.
34 <meta> Define metadatos sobre el documento. <meta charset="UTF-8"> Va dentro de <head>
35 <link> Enlaza recursos externos como CSS. <link rel="stylesheet" href="estilos.css"> Va dentro de <head>
36 <script> Define un bloque de código JavaScript. <script>alert("Hola")</script> Puede ir en <head> o <body>
37 <figcaption> Define una leyenda para una imagen o figura. <figure><img src="imagen.jpg"><figcaption>Leyenda de la imagen</figcaption></figure> Usado para describir imágenes o figuras
38 <figure> Define contenido gráfico como imágenes o diagramas. <figure><img src="diagrama.png"><figcaption>Diagrama</figcaption></figure> Contiene <img> y <figcaption>
39 <audio> Define contenido de audio. <audio controls><source src="audio.mp3" type="audio/mpeg"></audio> Usa el atributo controls para mostrar controles
40 <video> Define contenido de video. <video controls><source src="video.mp4" type="video/mp4"></video> Usa el atributo controls para mostrar controles
41 <canvas> Define un área de dibujo para gráficos dinámicos. <canvas id="miCanvas" width="200" height="100"></canvas> Usado con JavaScript para dibujar gráficos
42 <details> Define un widget de detalles que el usuario puede abrir o cerrar. <details><summary>Más información</summary><p>Detalles aquí</p></details> Usado para mostrar contenido adicional
43 <summary> Define un resumen para el elemento <details>. <details><summary>Ver más</summary><p>Contenido adicional</p></details> Va dentro de <details>
44 <mark> Resalta texto con un fondo amarillo. <mark>Texto resaltado</mark> Usado para destacar texto importante
45 <abbr> Define una abreviatura o acrónimo. <abbr title="HyperText Markup Language">HTML</abbr> El atributo title muestra el significado completo
46 <time> Define una fecha u hora. <time datetime="2024-06-01">1 de junio de 2024</time> El atributo datetime es para máquinas
47 <progress> Define una barra de progreso. <progress value="70" max="100">70%</progress> Usa los atributos value y max
48 <meter> Define una medida escalar dentro de un rango conocido. <meter value="0.6">60%</meter> Usa el atributo value para indicar la medida
49 <wbr> Define un punto de ruptura opcional dentro de una palabra. Supercalifragilistic<wbr>expialidocious No necesita etiqueta de cierre
50 <source> Especifica múltiples recursos multimedia para <audio> o <video>. <video controls><source src="video.mp4" type="video/mp4"></video> Va dentro de <audio> o <video>
51 <track> Define subtítulos o pistas de texto para multimedia. <track src="subtitulos.vtt" kind="subtitles"> Va dentro de <video>
52 <map> Define un mapa de imagen con áreas clickeables. <map name="mapa"><area shape="rect" coords="0,0,100,100" href="#"></map> Se usa junto con <img>
53 <area> Define un área dentro de un mapa de imagen. <area shape="circle" coords="50,50,40" href="#"> Va dentro de <map>
54 <col> Define propiedades para una columna en una tabla. <col style="background-color:yellow"> Va dentro de <colgroup>
55 <colgroup> Agrupa columnas dentro de una tabla. <colgroup><col span="2"></colgroup> Va dentro de <table>
56 <caption> Define el título de una tabla. <table><caption>Mi Tabla</caption></table> Va dentro de <table>
57 <thead> Agrupa el encabezado de una tabla. <thead><tr><th>Nombre</th></tr></thead> Va dentro de <table>
58 <tbody> Agrupa el cuerpo principal de una tabla. <tbody><tr><td>Dato</td></tr></tbody> Va dentro de <table>
59 <tfoot> Agrupa el pie de una tabla. <tfoot><tr><td>Total</td></tr></tfoot> Va dentro de <table>
60 <fieldset> Agrupa elementos dentro de un formulario. <fieldset><legend>Datos</legend></fieldset> Va dentro de <form>
61 <legend> Define el título de un <fieldset>. <legend>Información Personal</legend> Va dentro de <fieldset>
62 <datalist> Proporciona una lista de opciones para un <input>. <input list="opciones"><datalist id="opciones"><option value="HTML"></datalist> Va junto con <input>
63 <option> Define una opción dentro de <select> o <datalist>. <option value="1">Opción 1</option> Va dentro de <select>
64 <optgroup> Agrupa opciones dentro de un <select>. <optgroup label="Grupo 1"><option>A</option></optgroup> Va dentro de <select>
65 <textarea> Define un área de texto multilínea. <textarea rows="4" cols="30">Escribe aquí</textarea> Va dentro de <form>
66 <output> Muestra el resultado de un cálculo. <output name="resultado">0</output> Se usa con JavaScript
67 <b> Muestra texto en negrita sin significado semántico. <b>Texto en negrita</b> Solo cambia la apariencia
68 <i> Muestra texto en cursiva sin significado semántico. <i>Texto en cursiva</i> Solo cambia la apariencia
69 <u> Subraya texto. <u>Texto subrayado</u> Uso principalmente visual
70 <small> Define texto más pequeño. <small>Texto pequeño</small> Usado para notas o aclaraciones
71 <sub> Define texto en subíndice. H<sub>2</sub>O Usado en fórmulas químicas
72 <sup> Define texto en superíndice. X<sup>2</sup> Usado en potencias matemáticas
73 <del> Define texto eliminado. <del>Texto eliminado</del> Se muestra tachado
74 <ins> Define texto insertado. <ins>Texto agregado</ins> Se muestra subrayado
75 <blockquote> Define una cita en bloque. <blockquote>Esta es una cita larga</blockquote> Se muestra con sangría
76 <q> Define una cita corta en línea. <q>Cita corta</q> Agrega comillas automáticamente
77 <cite> Define el título de una obra. <cite>El Quijote</cite> Generalmente en cursiva
78 <dfn> Define un término que se está describiendo. <dfn>HTML</dfn> es un lenguaje de marcado. Indica definición
79 <kbd> Representa entrada de teclado. Presiona <kbd>Ctrl</kbd> + <kbd>C</kbd> Usado en atajos
80 <samp> Representa salida de un programa. <samp>Error 404</samp> Usado para mensajes del sistema
81 <var> Define una variable en programación o expresión matemática. <var>x</var> = 10 Se muestra generalmente en cursiva
82 <main> Define el contenido principal del documento. <main><h1>Contenido Principal</h1></main> Solo debe existir uno por documento
83 <address> Define información de contacto. <address>correo@ejemplo.com</address> Usado para datos del autor
84 <bdi> Aísla texto que puede tener dirección diferente (RTL/LTR). <bdi>Usuario</bdi> Útil en textos internacionales
85 <bdo> Controla la dirección del texto. <bdo dir="rtl">Texto</bdo> Usa el atributo dir
86 <dialog> Define un cuadro de diálogo. <dialog open>Mensaje</dialog> Puede abrirse con JavaScript
87 <template> Define contenido oculto reutilizable. <template><p>Plantilla</p></template> Se usa con JavaScript
88 <noscript> Define contenido alternativo si JavaScript está deshabilitado. <noscript>Activa JavaScript</noscript> Va dentro de <body>
89 <object> Incrusta contenido externo. <object data="archivo.pdf" type="application/pdf"></object> Puede contener <param>
90 <param> Define parámetros para <object>. <param name="autoplay" value="true"> Va dentro de <object>
91 <embed> Incrusta contenido externo directamente. <embed src="archivo.swf"> No necesita etiqueta de cierre
92 <picture> Permite mostrar imágenes adaptativas. <picture><source srcset="img.webp"><img src="img.jpg"></picture> Contiene <source> e <img>
93 <portal> Permite incrustar otra página con navegación avanzada. <portal src="https://ejemplo.com"></portal> Soporte limitado en navegadores
94 <data> Asocia contenido con un valor legible por máquina. <data value="12345">Producto</data> Usa el atributo value
95 <menu> Define una lista de comandos o menú. <menu><li>Opción</li></menu> Parecido a <ul>
96 <menuitem> Define un comando dentro de un menú. <menuitem label="Guardar"></menuitem> No soportado en HTML moderno
97 <dl> Define una lista de definiciones. <dl><dt>HTML</dt><dd>Lenguaje de marcado</dd></dl> Contiene <dt> y <dd>
98 <dt> Define un término en una lista de definiciones. <dt>HTML</dt> Va dentro de <dl>
99 <dd> Define la descripción de un término. <dd>Lenguaje de marcado para la web</dd> Va dentro de <dl>
100 <svg> Define gráficos vectoriales escalables. <svg width="100" height="100"><circle cx="50" cy="50" r="40"></circle></svg> Permite crear gráficos sin perder calidad
101 <iframe> Inserta otra página dentro de la actual. <iframe src="https://example.com"></iframe> Usado para videos, mapas, etc.
102 <meta> Define metadatos del documento. <meta charset="UTF-8"> Va dentro de <head>
